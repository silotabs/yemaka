# Local Contract Notes

Read-only contract and agreement note workflows for users who want local help
organizing clauses, obligations, dates, and questions before reviewing with a
qualified professional.

## Default Behavior

- Disabled until explicitly installed and enabled.
- Uses only pasted contract text, local memory, and ingested local documents.
- Does not use internet, connectors, scheduler, shell, file writes, or memory writes.
- Produces reviewable notes only; it does not give legal advice or update documents.

## Skills

- `contract_note_review`: summarizes contract notes into parties, dates,
  obligations, unclear clauses, and questions.
- `clause_question_list`: turns selected clauses into plain-language questions
  and review notes.

## Safety Notes

This pack is not a lawyer. It should not decide enforceability, interpret live
law, sign or submit documents, contact anyone, change files, or advise the user
what legal action to take. It should label assumptions and suggest qualified
professional review for legal decisions.
