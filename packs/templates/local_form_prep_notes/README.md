# Local Form Prep Notes

Read-only form-prep workflows for users who want local help organizing form
fields, application notes, document-prep context, missing details, and review
questions without filling, signing, submitting, uploading, emailing, or filing
anything.

## Default Behavior

- Disabled until explicitly installed and enabled.
- Uses only pasted form notes, local memory, and ingested local documents.
- Does not use internet, connectors, scheduler, shell, file writes, or memory writes.
- Produces reviewable notes only; it does not complete or transmit forms.

## Skills

- `form_field_checklist`: turns local form context into fields, missing
  details, assumptions, and review questions.
- `document_prep_review`: reviews local document-prep notes and organizes
  required documents, unclear items, and questions.

## Safety Notes

This pack must not fill, sign, submit, upload, email, mail, file, generate PDFs,
update files, schedule reminders, contact services, or store form details.
Legal, tax, medical, immigration, financial, benefits, eligibility, or
compliance decisions belong outside this pack and require the normal approved
path for that task.
