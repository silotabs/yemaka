# Local Security Privacy Notes

Read-only privacy and account-hygiene workflows for users who want help
organizing local notes into practical checklists and questions without running
tools against systems or connecting to services.

## Default Behavior

- Disabled until explicitly installed and enabled.
- Uses only pasted notes, local memory, and ingested local documents.
- Does not use internet, connectors, scheduler, shell, file writes, or memory writes.
- Produces reviewable notes and checklists only; it does not change account settings.

## Skills

- `privacy_note_review`: turns privacy settings or data-sharing notes into a
  clear review checklist and follow-up questions.
- `account_hygiene_checklist`: organizes account-safety notes into a local
  checklist for the user to review manually.

## Safety Notes

This pack is passive. It must not ask for secrets, store sensitive account
details, scan systems, inspect devices, test websites, run commands, connect to
accounts, or perform live security work. Active cyber or network assessment
belongs to the core safety gate, not this pack.
