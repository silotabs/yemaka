# Campaign Idea Review Workflow

## Steps

- Ask for content ideas, campaign notes, or local document scope if no context is provided.
- Use rag_search when the user references ingested local marketing notes, drafts, or campaign docs.
- Use memory_search only for user-stated audience, tone, or review preferences.
- Group ideas by theme, audience, format, assumptions, missing details, and questions to review.
- Keep suggestions as draft notes and avoid external claims.

## Verification Checks

- Do not post, publish, schedule, send, generate assets, update files, write memory, or search the web.
- Do not claim current trends, platform policy, audience performance, legal clearance, or brand approval.
- Do not repeat sensitive customer lists, private metrics, or unreleased campaign details unless needed for the requested review.

## Failure Handling

- If current performance or trend data is needed, require configured/approved search or provided source context.
- If the user asks for publishing or scheduling, route outside this pack.
- If context is missing, ask for the notes or local document scope.
