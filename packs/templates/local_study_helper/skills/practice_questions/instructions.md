# Practice Questions Workflow

## Steps

- Ask for the topic, difficulty, and local source scope if they are missing.
- Use rag_search to ground questions in ingested local notes or documents.
- Use memory_search for user-provided study goals or previously noted focus areas.
- Create a balanced set of recall, explanation, application, and compare/contrast questions.
- Include short answer keys and mark low-confidence items if source evidence is thin.

## Verification Checks

- Do not use internet search or connectors.
- Do not store grades, scores, or learning history.
- Keep answer keys grounded in local or user-provided material.

## Failure Handling

- If local sources are missing, ask the user to paste notes or ingest documents.
- If the source material conflicts, include both versions and ask which one to use.

## Example Prompts

- Create practice questions from my ingested lecture notes.
