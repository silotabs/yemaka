# Local Career Notes

Read-only workflows for organizing local resume notes, role descriptions,
interview notes, fit gaps, and preparation questions.

## Default Behavior

- Disabled until explicitly installed and enabled.
- Uses only pasted career notes, local memory, and ingested local documents.
- Does not use internet, connectors, scheduler, shell, file writes, or memory writes.
- Returns reviewable fit summaries and preparation notes; it does not apply,
  contact people, send messages, or update files.

## Skills

- `resume_fit_review`: compares local resume notes with a role description and
  lists fit signals, gaps, questions, and evidence.
- `interview_note_prep`: organizes local interview notes into themes, likely
  questions, examples to prepare, and follow-up questions.

## Safety Notes

This pack should keep career material local and reviewable. It should not make
external claims, search postings, send messages, schedule reminders, or store
personal details.
