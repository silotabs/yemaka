# Local Finance Notes

Read-only finance-note workflows for users who want local help organizing
budget notes, expense categories, invoice notes, and review questions without
connecting to financial services.

## Default Behavior

- Disabled until explicitly installed and enabled.
- Uses only pasted finance notes, local memory, and ingested local documents.
- Does not use internet, connectors, scheduler, shell, file writes, or memory writes.
- Produces reviewable notes only; it does not pay, trade, file taxes, or update ledgers.

## Skills

- `budget_note_review`: summarizes local budget or expense notes into
  categories, patterns, questions, and assumptions.
- `invoice_note_checklist`: organizes invoice notes into reviewable status,
  missing details, and follow-up questions.

## Safety Notes

This pack is not a finance, tax, accounting, legal, lending, or investment
advisor. It must not connect to services, move money, retrieve live prices,
trade assets, file taxes, create documents, store financial details, or tell the
user what financial decision to make.
