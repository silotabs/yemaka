# Local Travel Notes

Read-only travel-note workflows for users who want local help organizing trip
notes, itinerary drafts, packing lists, and questions without booking,
searching, or connecting to travel services.

## Default Behavior

- Disabled until explicitly installed and enabled.
- Uses only pasted travel notes, local memory, and ingested local documents.
- Does not use internet, connectors, scheduler, shell, file writes, or memory writes.
- Produces reviewable notes only; it does not book, pay, send, cancel, or schedule anything.

## Skills

- `trip_note_brief`: summarizes local trip notes into itinerary items,
  constraints, missing details, and questions.
- `packing_itinerary_checklist`: organizes packing notes and itinerary context
  into a manual checklist.

## Safety Notes

This pack must not provide live prices, availability, weather, current travel
advisories, visa or immigration advice, medical travel advice, legal advice, or
booking actions from local context. Current or external travel facts require the
normal approved internet/search path, and bookings or messages require
connector/action paths outside this pack.
